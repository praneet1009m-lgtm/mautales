# The Mau Tales — 3D scrapbook portfolio

A scrapbook-style portfolio website for the creator **Mansi Patil (The Mau Tales)**.
Scroll through a paper scrapbook with stickers, tape, polaroids you can drag, handwriting that
writes itself, and a **realistic 3D page turn** between sections.

- Live site: https://mautales.vercel.app
- Repo: https://github.com/praneet1009m-lgtm/mautales

Built with **Vite** (dev server + build), **three.js** (page curl), **GSAP + ScrollTrigger**
(animations), **Lenis** (smooth scroll) and **html-to-image** (photographs sections into page textures).

## Folder map

```
.
├── index.html            All page content (cover, hero, moments, about, services, content, contact)
├── src/
│   ├── main.js           All behaviour: effects, scroll scenes, 3D page turn, loading cover
│   └── style.css         All styling (variables first, then one block per section, phone overrides last)
├── public/               Files copied as-is into the build
│   ├── img/              Photos and stickers (hero, about, services, contact)
│   ├── yt/               YouTube thumbnails
│   ├── tex/              Paper grain textures (noise, fiber, blot)
│   ├── audio/            Background song
│   └── turn/             Ready-made page-turn textures, one folder per screen size + manifest.json
│                         (generated by `npm run prerender` — don't edit by hand)
├── prerender.mjs         Makes the public/turn textures for 16 common screen sizes
├── prerender-pack.py     Helper for prerender.mjs: crops, de-duplicates and compresses the textures
├── *.mjs / sheet.py      Small developer tools (screenshots, recordings, speed tests) — see the top
│                         of each file. Not used by the website itself.
├── .prettierrc           Code formatting rules (Prettier)
└── package.json          Scripts and dependencies
```

Where to look for things in `src/main.js` (search for the `=====` banners):
1. **SETUP** – smooth scroll, helpers
2. **SMALL EFFECTS** – torn edges, handwriting, paper-plane cursor, drag physics, flutter, hanging cards, music, contact form, YouTube popup
3. **SCROLL SCENES** – `build()`: the animation of each section
4. **PAGE TURN** – the three.js page curl (`snapshot`, `crop`, `make`, `draw`, `drawM`, `kill`)
5. **LOADING COVER** – `boot()`

## Run it

```bash
npm install          # once
npm run dev          # local dev server (http://localhost:5173)
npm run build        # production build into dist/
npm run preview      # serve the built dist/ locally
```

Format the code with `npm run format` (check only: `npm run format:check`).

### Regenerating the page-turn textures (only needed if the page content/layout changes)

The page curl needs a picture of each page. For the common screen sizes these are made ahead of
time and stored in `public/turn/`; for any other size the browser captures them itself after load
(takes a few seconds).

```bash
npx playwright install chromium   # once
pip install pillow                # once, used by prerender-pack.py
npm run build
npx vite preview --port 4210 &    # keep this running
npm run prerender                 # writes public/turn/*
npm run build                     # rebuild so dist/ contains the new textures
```

`npm run build:full` does all of the above in one go. `ONLY=m npm run prerender` redoes just the
phone sizes (`ONLY=d` for desktop).

## How deploy works

The site is a static build hosted on **Vercel** (project `mautales`).
GitHub → Vercel auto-deploy is **not** connected, so deploys are manual:

```bash
git push                # saves the code to GitHub (praneet1009m-lgtm/mautales)
npx vercel --prod       # builds and publishes to https://mautales.vercel.app
```

(Vercel needs to be logged in once with `npx vercel login`.)
